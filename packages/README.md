# packages

Monorepo shareable. `apps/*` deployable, `packages/*` importable via `workspace:*`.

- **@ibisa/types** — shared contracts (ProgramItem, etc) untuk web & api
- **@ibisa/domain** — entity SLB
- **@ibisa/application** — use-case
- **@ibisa/infrastructure** — adapter DB/API
- **@ibisa/config** — eslint/tsconfig/tailwind preset
