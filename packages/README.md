# packages

Monorepo shareable. `apps/*` deployable, `packages/*` importable via `workspace:*`.

- **@bisa/domain** — entity SLB
- **@bisa/application** — use-case
- **@bisa/infrastructure** — adapter DB/API
- **@bisa/config** — eslint/tsconfig/tailwind preset
