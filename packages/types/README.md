# @bisa/types

Shared TypeScript contracts untuk `apps/web` & `apps/api`.
Aturan: tipe data murni saja — dilarang import React / tipe UI.

Live:
- `member.ts` — `Gender`, `MemberStatus`, `Member`, `ClassOption`,
  `MemberCreateBody` (POST teachers/students), `MemberUpdateBody` (PUT users/:id).

Rencana berikutnya: `ProgramItem`, `TestimonialItem`, `FooterLink` dari web.
